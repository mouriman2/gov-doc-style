# 省庁の資料の書き方（gov-doc-style の参照）

元の調査: [docs/measurements.md](../docs/measurements.md)（2026-10-01、各省の公開 PDF 10 本を測った）。
数字の目安は `src/gov_doc_style/specs.py` と同じ。ここは中身を書くときに見る。

## 種類の選び方

| 頼まれた中身 | ひな形 | 目安 |
|---|---|---|
| 1 つの事業・施策を 1 枚で説明する（目的・仕組み・目標がある） | `ponchi-jigyo.html` | 1 枚 700〜1,600 字、本文 A4 換算 11〜16pt |
| たくさんの事柄（現状・評価・方針など）を 1 枚に全部載せる | `ponchi-gaiyo.html` | 1 枚 1,500〜2,800 字、7.5〜11.5pt |
| 1 枚に入らない説明。会議で配る「資料１」 | `deck.html` | 本文の紙 1 枚 400〜1,600 字、10.5〜16pt |
| お知らせ・依頼・照会の文書 | `tsuchi.html` | A4 縦 1 枚 300〜1,440 字、10.5pt 明朝 |

迷ったら、読み手が「1 枚だけ見て済ませる」ならポンチ絵、「説明を聞きながら順にめくる」なら説明資料。

## 文の書き方

- **資料（ポンチ絵・説明資料）は である体と名詞止め。** 目的は「本事業は、〜により、〜を図ることを目的とする。」。
  箇条書きは「〜の推進」「〜の強化」「〜を実施」と名詞や動詞の終止形で止める
- **通知は です・ます体。**「〜についてお知らせします」「〜をお願いします」。前文は「平素より、〜に御協力いただき、厚く御礼申し上げます。」
- **「等」は 100 字に 1 回くらい。** 予算の資料 7 本のうち 6 本が千字に 8.8〜11.7 回。列挙の最後に付ける（「撮影、テキスト化等」）。
  検査の目安は千字に 4〜15 回で、**少なすぎても注意が出る**（型から外れて見える）。かぎ括弧で引いた「等」は数えない
- **年は和暦。** 「令和８年度」。資料の年は年度で書くことが多い。西暦は使わない（9 本で和暦 895 回・西暦 114 回）
- **数字の書き方（実物で見た慣行）。** 文中の 1 桁は全角、2 桁以上は半角（「令和８年10月１日」「17億円（15億円）」）。
  3 桁ごとにコンマ。兆・億・万は漢字（「5,000万円」「1.2兆円」）。数字と単位の間に空白を入れない。
  大きく見せる金額（概算要求額）と表の数値の列は、1 桁でも半角にしてよい（全角は太字で幅が広く見え、表の桁もそろわない）
- **英字の語と和文の間は詰める**（「PNG及びPDF」「EBPMの推進」）。1 枚の中でそろっていることのほうが大事
- **漢字の使い分け（公用文）。** 「及び」「並びに」「又は」「若しくは」「御」（御協力・御確認）は漢字
- **括弧。** （ ）と「 」が基本。【 】は項目名（【本件担当】）。前年度の額は丸括弧（「12億円（10億円）」）

## 見出しと記号

- 見出しの階層: **第１ → １ → （１） → ア → （ア）**（公用文作成の考え方）。スライドでは「１．」「（１）」「①」もよく使う
- 箇条の記号は階層で使い分ける: ◆ → ○ → ・。注は「※」で小さく
- 強調は 1 枚に 2 種類以上: **赤字＋下線**（`<u class="r">`）・**黄色の蛍光ペン**（`<mark>`）・太字。
  使うのは数字と決定事項だけにし、1 区画に 1〜2 か所まで
- 区画は **紺の帯見出し＋細い枠**（`<section><h2>`）で 2〜5 個。番号を振る（「１　現状（主要指標）」）
- 図は **箱と赤い太矢印**。「国 →（補助（１／２））→ 地方公共団体」のように矢印の上に関係を書く。
  補助の流れ以外（A → B → C の連鎖、手順の列）は、`ponchi-gaiyo.html` の `.flow`（箱・矢印・枠で囲んだ手順・出力の箱）を流用するか、
  `.scheme` の `grid-template-columns` を箱と矢印の数に合わせて書き換える

## 上端と下端に入れるもの

| 場所 | ポンチ絵・説明資料 | 通知 |
|---|---|---|
| 左上 | 表題（大）。予算なら横か下に「令和○年度概算要求額 ○億円（○億円）」 | 宛先「各都道府県○○主管課長　殿」 |
| 右上 | 担当の局・課名（内線）、または枠つきの日付と決定の種類（「令和７年６月13日 閣議決定」）、会議資料なら「資料１」 | 文書番号と日付、その下に発信者「（公印省略）」 |
| 表題の左 | 丸い印「新規」「拡充」「継続」 | ― |
| 下 | 「※」の注、出典、ページ番号（右下） | 「以上」の後、右下に【本件担当】の枠 |

## 紙と書体

- ポンチ絵・説明資料は **275×190mm 横**（PowerPoint でスライドのサイズに「A4」を選んだ大きさ）。本物の A4 より 16% 小さく、刷ると 1.08 倍になる
- 書体は **Meiryo UI**（実物 10 本で最多）。数字も同じ書体
- 通知は **A4 縦（210×297mm）・MS 明朝 10.5pt・40 字×36 行前後**

## 詰め方

省庁の資料は「1 枚で全部答える」ために詰める（当事者の証言）。それらしく見せるには:

- **余白を残さない。** 区画の下に 8mm（本文 1 行強）を超える空きがあると検査で注意が出る。埋め方は、中身を足す →
  字を大きくする → 区画の中身を上下に散らす（`.in` に `spread` クラス。ひな形の CSS にある）→ 区画の高さの配分を変える
- **はみ出したら、削るのは説明の言葉。** 区画や項目は減らさない（1 回目にポンチ絵を作ったとき、実際にこうなった）。
  それでも入らなければ字を小さくする（検査の下限まで）。下限を割るなら 2 枚に分ける
- 注・出典・前年度の額など、細かい情報も載せる。注は小さくてよい

## HTML を書くときの注意

- **和文の文を HTML の中で途中改行しない。** ブラウザは改行を半角の空白にする（「ことにより、 人が」）。1 文は 1 行に書く。検査で「改行の空白」の注意が出る
- 赤字下線・蛍光ペンを含む文を `display: flex` の箱に直接入れない。強調した部分だけが別の行に割れる。`<div>` で 1 段包む
- `position: absolute` で中身を置かない。重なりを検査で拾えない
- はみ出しの量は mm で出る（CSS の 1px ≒ 0.26mm）。本文 1 行は 6mm 前後
- その資料だけの CSS の調整（ラベルの幅、行の高さ等）は `</style>` の直前に足す。ひな形の同じ規則より前に置くと効かない
- 語の途中で折れる（「ひ／な形」「解／約」）ときは、言い換えて短くするか `<span style="white-space: nowrap">` で包む
- 指標の区画（KPI と棒グラフ）に `spread` を付けると、塊の間に帯のような空白ができる。棒を太く・字を大きくして埋めるほうが自然

## やってはいけないこと

- **実在の省庁・自治体の名義で作らない。** 組織名は「○○省 ○○局」の伏せ字か、架空の名前か、本人の名前（「決裁：本人 事務局：Claude」）
- 公印・省庁のロゴを模さない。本物の通知と見分けがつかないもの（実在の文書番号・実在の担当者名）を作らない
- **数字をでっち上げない。** 分からない数字は「○億円」「○団体」と伏せて、何が足りないかを本人に伝える。見本の数字は架空と注に書く
